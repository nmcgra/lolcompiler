Executable Target:
This build of lolcompiler uses macOS and Google Chrome web browser for HTML output preview.  
The compiler was built as a single-file executable using `cargo build --release`.

AI / LLM Usage:
AI tools (specifically ChatGPT and DeepSeek) were used to assist with debugging, refining module organization, and improving code funtionality (such as fixing an infinite loop in the parser).  
Assistance was also used to clarify Rust syntax and obscure code segments, ensure proper argument parsing, and verify that the final build met all project specification requirements. Mainly, the AI
models were used to refine code and help diagnose where the major issues stemmed from.
